一站式AI副业工具，集成了 **5大赚钱工具** + **12个高质量提示词模板**，帮助你快速接单赚钱。

| 工具 | 功能 | 接单价 |
|------|------|--------|
| ✍️ 营销文案生成器 | 朋友圈/公众号/详情页/小红书/销售信 | ¥50-500/篇 |

## 🚀 如何使用

1. 打开 `index.html` 或部署到 Vercel
2. 输入你的 Anthropic API Key
3. 选择工具 → 填写信息 → 点击生成
4. AI 生成专业级内容 → 复制 → 交付客户
